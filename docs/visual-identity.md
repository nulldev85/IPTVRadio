# Aether visual identity

## Color modes

Light uses warm paper and forest ink. Dark uses deep green charcoal and soft
ivory. Both are deliberately quiet so station marks and album artwork provide
the changing color. The listener can choose Light, Dark, or System in Settings.

| Role | Light | Dark |
| --- | --- | --- |
| Canvas | `#F5F3EC` | `#111A14` |
| Surface | `#FFFEF9` | `#1B271E` |
| Navigation surface | `#EDF0E8` | `#1B281F` |
| Main text | `#222B25` | `#F2F0E7` |
| Supporting text | `#576359` | `#C3CDC0` |
| Inactive icons | `#5E705F` | `#AEBFAE` |
| Active controls and favorites | `#2B664C` | `#B5D4B3` |
| Soft active surface | `#D8E8DA` | `#304938` |
| Hairlines | `#D0D9CE` | `#3B4C3E` |

Large screen headings use the system serif face. Station names and controls
stay in the system sans face for fast scanning. Rows use a thin inset rule;
channel logos sit directly on the canvas with a small adaptive edge shadow.
The app icon is an Æ lettermark rendered from
`scripts/generate-aether-icon.py`.

## Player

The fullscreen vinyl player and its preview bar use the same appearance as
the rest of the app. Their artwork, vinyl motion, layout, and playback controls
stay the same. A light or dark artwork veil keeps song text legible against a
blurred album cover.
